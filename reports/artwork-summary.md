## Cache operations

The local cache is `rpw/static/artwork_cache/` and is intentionally Git-ignored. Back it up with:

```sh
tar -czf rarepepe-artwork-cache.tar.gz rpw/static/artwork_cache
```

Restore that directory unchanged before starting Flask. The manifest is `rpw/static/artwork_cache/manifest.json`; resumable request checkpoints are in `progress.jsonl`.

## Policy and audit method

RarePepes.com robots policy: robots.txt allows this path. TokenScan has no published robots.txt (404). Requests were sequential with host pacing, retries, Retry-After handling, MIME/signature/decode validation and no full-image bulk scraping outside assets that required the RarePepes.com fallback.
